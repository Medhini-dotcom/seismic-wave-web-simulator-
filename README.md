# 🌋 SeismoLab — Interactive Seismology Explorer

An interactive web-based educational tool and seismic simulator designed to visualize earthquake mechanics, body wave propagation, synthetic seismograms, and station triangulation.

## ✨ Features
* **Wave Laboratory:** Simulates expanding primary (P), secondary (S), and surface waves radiating from an adjustable hypocenter.
* **Synthetic Seismogram Generator:** Dynamically plots vertical ground-motion traces and calculates arrival times based on standard crustal velocities.
* **Epicenter Locator:** Demonstrates S–P time gap triangulation across multiple simulated seismic stations.
* **Interactive Controls:** Adjust simulation time, station distance, and earthquake magnitude in real time.

## 🛠️ Built With
* **HTML5 Canvas** (Custom graphical rendering)
* **CSS3** (Responsive layout and modern UI styling)
* **JavaScript (ES6+)** (Real-time state and wave physics calculations)
